# InfoNews

Projeto desenvolvido como atividade prática da disciplina de Desenvolvimento Web do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 📌 Sobre o projeto

O InfoNews é um site desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, principalmente a criação e organização de páginas, navegação entre diferentes seções e estruturação de uma interface web.

O projeto foi desenvolvido como atividade acadêmica e contou com o auxílio de Inteligência Artificial durante o processo de desenvolvimento.

## 🚀 Funcionalidades

- Página inicial;
- Página de login;
- Página de cadastro;
- Página de perfil;
- Página de regiões;
- Página "Sobre";
- Área administrativa (CMS);
- Navegação entre as páginas do site.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
